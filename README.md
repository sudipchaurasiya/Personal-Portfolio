# Personal Portfolio Website

## About the Project

This is my personal portfolio website created using semantic HTML5. The purpose of this project is to present my personal information, education, technical skills, projects, cybersecurity interests, and contact information in a simple single-page website.

The website was created as part of my CSE 230 Web Design and Developments assignment.
